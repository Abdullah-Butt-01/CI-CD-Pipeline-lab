# Project: Automatic Docker Build Pipeline

## Objective

* Create a automated Docker Build pipleline

## Commands Practiced

* sudo systemctl restart NetworkManager

## What I did

* Created python app, requirements file, and Dockerfile
* First, built image locally and tested from browser
* Created github workflow structure and file (yml file)
* Pushed to github
* Image built and pushed to Dockerhub
* Pulled image from Dockerhub and tested a container

## Problems Faced

* Error building image, can not pull dependencies
* Pushed Workflow file before adding secrets to github

## How I solved

* Restarted network services
* Always add secrets first

## Key Learnings

* Automated pipeline
* Docker image built
* DockerHub integration
* Github Actions Workflow
